# 내 단어장

아이폰 Safari에서 사용하는 개인 단어장·학습 웹앱입니다.

게시 주소: https://chos22.github.io/my-vocabulary/

Safari에서 위 주소를 연 뒤 공유 → 홈 화면에 추가로 설치할 수 있습니다.

## 기능
단어장 추가와 편집, 단어·뜻·메모·별표, 플래시카드·객관식·받아쓰기·자동재생, 오답노트, 구간 학습과 이어하기, CSV·JSON 백업 및 복원, 7일 삭제 복원.

## 데이터
단어와 학습 기록은 사용하는 기기의 브라우저 안에 저장됩니다. 이 저장소로 전송하거나 자동 동기화하지 않습니다. Safari 데이터를 삭제하거나 기기를 바꾸기 전에는 JSON 백업을 보관하세요.

## 기존 앱에서 이전
기존 주소의 설정에서 JSON 백업 → 새 주소를 홈 화면에 추가 → 새 앱의 설정에서 파일 가져오기 → 복원 확인 순서로 진행하세요. 기존 앱은 복원 확인까지 유지하세요.

## 게시 설정
GitHub Pages: main 브랜치의 /(root) 폴더. 빌드·AI API·ChatGPT 구독 없이 실행됩니다.

일부 학습·탭 아이콘은 원보카 앱을 참고한 개인 학습용 자산입니다. 해당 원본 권리는 원 저작권자에게 있습니다. 원보카 공식 서비스와 연동되거나 운영사가 제공하는 앱이 아닙니다.
